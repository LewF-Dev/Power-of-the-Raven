# Power of the Raven

A version-specific Assassin's Creed Valhalla mod investigation for using the Dawn of Ragnarök Raven form in the main game without Cheat Engine or entering the DLC map first.

## Status

Reverse engineering is in progress for game version 1.7.0. The supplied Cheat Engine table shows which runtime routines the proof of concept changes, but it does not show how to load the Raven ability data on a fresh main-game launch. That loading path is the key unresolved part.

See [the initial reverse-engineering notes](docs/initial-reverse-engineering.md).

## Safety and scope

The Cheat Engine table is treated as reference data and is not executed or included in this repository. Do not commit game executables, Forge archives, saves, or other files copied from the game installation.
